# decision-model-eval

Do cheap decision models hold decision quality at the judgment points of a real agentic workflow, and are their probabilities honest enough to set working points on?

This project measures that per decision point and per backend on a live job-search pipeline, against labels and a non-model baseline. **Work in progress** - the methodology and results will be written up here as they land.

Developed using Claude Code; `CLAUDE.md` contains the technical context file for AI-assisted sessions.
